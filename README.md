# ЖК «Связь Времён» — демоверсия

Статическая версия сайта для согласования дизайна на GitHub Pages.

Адаптивная вёрстка, интерактивная карта, переключатели квартир, калькулятор и модальные окна работают в браузере.

Отправка заявок и аналитика в демоверсии отключены. Формы показывают сообщение о режиме просмотра и не отправляют данные на сервер.

Файлы публикуются из корня ветки `main`; `.nojekyll` сохраняет обычную HTML/CSS/JS-структуру.
